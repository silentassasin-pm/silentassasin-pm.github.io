Plutus

A dashboard that tracks 44 indicators against the investment theses I'm actually holding, so that when I change my mind about a position I have to do it against evidence rather than mood. I use it most days.

Python · Streamlit · Google Sheets 8,211 LOC 44 indicators

I grew up in a family that was, in my own phrase, comfortably poor, with no generational wealth and no safety net, and I've since watched money do strange things to my own head. Plutus exists because I don't trust my gut on my own portfolio, and I wanted the thesis for every position written down with the indicators that would falsify it sitting next to it.

Each active thesis carries its own indicator set, so the question a position has to answer is never "is it up" but "is the reason I bought this still true". Six of the 44 indicators were added in the v3 pass specifically to track AI-sector exposure.

This is a tool built for one user, which is the reason it's allowed to be opinionated. It is not investment advice and it isn't trying to become a product.
